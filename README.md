# 🏏 IPL Analyzer

A data analysis project based on Indian Premier League (IPL) match data.  
This project uses Python and popular data analysis and visualization libraries to explore IPL statistics, team performance, players, match results, and other interesting insights.

## 📊 Project Overview

The IPL Analyzer performs exploratory data analysis (EDA) on IPL match data to answer questions such as:

- 🏆 Which teams have won the most matches?
- 👑 Which players have performed consistently well?
- 🎯 Who are the top run scorers?
- 🔥 Which players have the most high scores?
- 🏟️ How do teams perform across different seasons?
- 📈 What patterns and trends can be found in IPL matches?

## 🛠️ Technologies Used

- **Python**
- **Pandas** – Data cleaning and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Jupyter Notebook** – Development and analysis
